# 🐉 Choose Your Own Adventure Game

A text-based adventure game built with Python where every choice leads to a different outcome. Explore a mysterious forest, navigate an abandoned city, and face a dragon that challenges you with riddles.

## 🎮 About the Project

This is my first mini-project in my **Python-21-day** challenge. The goal is to practice Python fundamentals by creating an interactive, choice-based story.

Players enter their name, choose their path, make decisions, and experience different endings based on their choices.

## ✨ Features

- **Interactive Story:** Explore the Dark Woods and the Lost City.
- **Multiple Paths:** Make decisions that influence the adventure.
- **Dragon's Challenge:** Answer yes-or-no riddles to escape the dragon's cave.
- **Score System:** Earn points for completing challenges.
- **Lives System:** Track remaining lives during the adventure.
- **Input Handling:** Accept user choices regardless of capitalization.

## 🛠️ Technologies Used

- Python 3
- Built-in functions: `print()` and `input()`
- Strings and variables
- String concatenation
- Conditional statements: `if`, `elif`, and `else`
- Nested conditionals
- String methods: `.lower()` and `.strip()`

## 🚀 How to Run

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/Python-21-day.git
```

**2. Navigate to the project folder**

```bash
cd Python-21-day/01-choose-your-own-adventure
```

**3. Run the game**

```bash
python main.py
```

Make sure Python 3 is installed on your system.
