# 🧮 Text-Based Calculator

A simple command-line calculator built with Python that performs basic arithmetic operations on user-provided numbers.

This project is part of my **21 Days of Python** challenge, where I practice Python fundamentals by building small, practical projects.

## ✨ Features

- **Addition (`+`)**: Adds two numbers.
- **Subtraction (`-`)**: Subtracts the second number from the first.
- **Multiplication (`*`)**: Multiplies two numbers.
- **Division (`/`)**: Divides the first number by the second, with division-by-zero protection.
- **Exponentiation (`**`)**: Raises the first number to the power of the second.
- **Modulus (`%`)**: Returns the remainder after division.
- **Input Validation**: Repeatedly asks for a valid number if the input cannot be converted to a number.

## 🛠️ Tech Stack

- **Language:** Python 3
- **Interface:** Command-Line Interface (CLI)
- **Concepts Used:** Functions, loops, exception handling, user input, conditional statements, and arithmetic operators.

## 🚀 Getting Started

### Prerequisites

Install Python 3 on your system.

Check your Python installation:

```bash
python --version
```

### Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/satyamk550/21-Days-of-Python.git
   ```

2. Navigate to the calculator directory:

   ```bash
   cd 21-Days-of-Python/02-text-based-calculator
   ```

3. Run the program:

   ```bash
   python main.py
   ```
