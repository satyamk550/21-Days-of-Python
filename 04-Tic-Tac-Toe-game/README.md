# 🎮 Tic-Tac-Toe Game in Python

A simple command-line Tic-Tac-Toe game built using Python. Two players take turns marking spaces on a 3×3 board using **X** and **O**. The first player to get three marks in a row, column, or diagonal wins!

## 📌 Project Overview

This project is part of my Python learning journey. I built this game to practice fundamental Python programming concepts and understand how to implement game logic using functions, loops, lists, and conditional statements.

## ✨ Features

- 3×3 Tic-Tac-Toe game board.
- Two-player gameplay (X and O).
- Players take turns making moves.
- Input validation for row and column selection.
- Prevents players from selecting an already occupied position.
- Checks all possible winning combinations.
- Detects the winner.

## 🛠️ Technologies Used

- **Language:** Python 3
- **Concepts:** Functions, Lists, Loops, Conditional Statements, Enumerate, Break and Continue.

## 🎯 How to Play

1. The game starts with an empty 3×3 board.
2. Player X makes the first move.
3. Enter the row and column number to select a position.
4. Player O takes the next turn.
5. Continue alternating turns until a player wins or the game ends in a draw.

### Example Board

```text
  X | O | X
-----------
  O | X | O
-----------
  X |   |  
```
